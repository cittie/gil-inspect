# 自定义变量类型 id -> 名字
#
# 与 node-types.txt 同一套思路：`.gil` 为每个变量声明的类型存了一个内部 id，
# 所以这个文件把 id 映射成名字。工具**只读**它；除了我们自己在关卡上验证过的 id 之外，
# 仓库里不附带任何别的东西，你也可以按自己的来源随意扩充。
#
# 格式：id<TAB>名字     （'#' 开头是注释）
#
# 这三条于 2026-10-05 实测确认 —— 用的是"建房时已知类型"的变量，所以是事实而非猜测：
#
#	4	布尔		(isBase)
#	10	浮点		(spawn_interval)
#	21	元件ID		(spawn_unit)
#
# 它们已经内置在工具里；写在这里只是为了说明格式。
# 未映射的 id 会在 -lint 报告里显示成 "type N（未映射）" 并附上变量名，
# 通常已经足够辨认它是什么。
#
# 4	布尔
# 10	浮点
# 21	元件ID
