# Second batch (2026-10-07): derived from a community compound-node pack (.gia).

# Method: an asset pack stores 87 compound-node DEFINITIONS (kind marker 12, carrying the
# display name) followed by 87 IMPLEMENTATIONS (kind marker 9, carrying the graph). The id
# fields are kind markers, not identities, so the pairing is POSITIONAL:
# definition #N <-> implementation #N. Each node is stored twice (an f2/f3 duplicate pair),
# so raw counts must be halved.

# verified from our own level, and the pack's "[执行]根据实体类型执行节点" independently
# resolves to the same id.
